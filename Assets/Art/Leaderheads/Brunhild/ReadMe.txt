This leaderhead is a converted model from TERA (http://en.wikipedia.org/wiki/TERA_Rising). Therefore, while heavy modifications of the models and artwork were made by me, I take no credit for both and all rights are with Bluehole Studio.

This leaderhead uses a slightly modified Ragnar Lodbrok animation set (only to correct glitches). It's completely modular. All files in the zip-file are already put into the necessary folders, unzipping it directly in the Mods folder of BtS should result into a working mod. It has a polycount of about 12500 triangles. There is only a shader version included.
